# assets/

Files shipped inside the After Effects panel.

- `social-templates.aep` — the social post template project. One comp per post type; a comp
  counts as a template when it has a `Theme · controls` layer with a `Dark mode` checkbox.
  Collect Files before saving here so any footage sits in `(Footage)/` next to it.

Anything in this folder is packaged as-is. Keep it to what the panel needs.
